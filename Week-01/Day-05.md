# Day 05 — First AI Automation

## What I Worked On

- Built a simple AI automation workflow using n8n.
- Explored how a workflow can receive user input, send it to an AI model, process it and produce an organised output.
- Worked with a feedback summarizer workflow using a form submission, AI processing and Google Sheets.
- Learned how to pass a user's feedback dynamically into an AI prompt.
- Structured the workflow to collect the user's name and feedback, generate a summary and save both the original feedback and AI-generated summary.

## Workflow

User Input → AI Process → Output

Google Form → Automation → AI Model → Summary → Google Sheets

## Reflection

Today I moved from learning about AI and automation separately to combining them in one practical workflow. It helped me understand how AI can be integrated into automated processes to handle information and produce useful outputs.
